PoultryOS mobile demo

A working prototype on the Supabase seed data (VKR Poultry Farms, KS Farms). Every list has an + Add; every record can be acted on. Changes live in this browser session.

Try these

  • Home quick actions: mortality, sale, payment, attendance in two taps.
  • Farm: add farm / shed, place a batch, record mortality, mark vaccination, add vet visit, close batch.
  • Log: daily entry with photo → AI check.
  • Money: new sale, new bill, receive or pay, GST, Tally export.
  • More → People: today's attendance + monthly register (tap any day), wages, advances.
  • More → Equipment: asset list, report issue → ticket, close with cost, service done.
  • Platform console: add tenant, manage plan.

Live feed

Home simulates supervisors' logs, rate updates and sensor alerts arriving in real time (Supabase Realtime in the product) — one every 40 seconds.
